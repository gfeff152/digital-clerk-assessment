# 王牌店員學習站｜第一單元評量

十題單選評量，主題是「24 小時王牌數位店員」。

- 每題答對後才能前往下一題。
- 選錯會標示錯誤選項並提供提示，可繼續嘗試。
- 完成十題後顯示評量完成訊息與通關密碼。
- 支援手機、鍵盤操作與同一瀏覽器的進度保存。

## 開始作答

網站使用 GitHub Pages 發布，公開網址以此儲存庫的 **Settings → Pages** 顯示為準。作答不需要登入。

## 原始碼與 VS Code 專案

儲存庫根目錄的 `index.html`、`styles.css`、`questions.js`、`quiz-core.js`、`app.js` 是實際發布的網站原始碼。

完整的 VS Code 開發專案另存於 [assessment-vscode.zip](./assessment-vscode.zip)，含本機預覽伺服器、VS Code 啟動設定、題庫、14 項測試與驗收紀錄。下載解壓後，以 VS Code 開啟 `assessment-vscode` 資料夾即可。

題目及通關密碼可在 `questions.js` 修改。目前依需求將密碼設為 `*****`。

此站為教學練習，答案與通關密碼儲存在前端檔案，不適合作為需要保密答案的正式考試。
