# 王牌店員學習站｜四章評量

首頁提供四章評量入口。每章為 10 題單選題，各章進度分開保存。

- 第一張評量：24 小時王牌數位店員（已開放）。
- 第二章評量：負評回應與顧客服務（已開放）。
- 第三章評量、第四章評量：題目待提供。

- 每題答對後才能前往下一題。
- 選錯會標示錯誤選項並提供提示，可繼續嘗試。
- 完成十題後顯示評量完成訊息與通關密碼。
- 支援手機、鍵盤操作與同一瀏覽器的進度保存。

## 開始作答

**[直接開始評量](https://gfeff152.github.io/digital-clerk-assessment/)**，不需要登入。

每一章答對才能前往下一題；完成後顯示對應評量編號與 `*****`。返回選單、重新整理及切換章節都可保留進度。重新開始僅清除目前章節。

## 原始碼與 VS Code 專案

儲存庫根目錄的 `index.html`、`styles.css`、`questions.js`、`quiz-core.js`、`app.js` 是實際發布的網站原始碼。

完整的 VS Code 開發專案另存於 [assessment-vscode.zip](./assessment-vscode.zip)，含本機預覽伺服器、VS Code 啟動設定、四章題庫、自動測試與驗收紀錄。下載解壓後，以 VS Code 開啟 `assessment-vscode` 資料夾即可。

題目及通關密碼可在 `questions.js` 修改。目前依需求將密碼設為 `*****`。

此站為教學練習，答案與通關密碼儲存在前端檔案，不適合作為需要保密答案的正式考試。
